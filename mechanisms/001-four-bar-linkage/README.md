# 001 Four-bar Linkage (4절 링크)

회전하는 입력 하나로 원하는 궤적의 출력 운동을 만들어내는, 링크 매커니즘 중 가장 기본이 되는 구조입니다. 100개 매커니즘 시리즈의 첫 번째 항목으로, 모든 링크 매커니즘의 출발점이라 첫 순서로 선택했습니다.

## 원리 설명

4절 링크는 이름 그대로 4개의 링크(막대)가 핀 조인트로 연결되어 폐곡선을 이루는 구조입니다. 그중 하나는 움직이지 않는 고정 링크이고, 나머지 세 개가 크랭크, 커플러, 로커 역할을 하며 움직입니다. 어느 링크가 가장 짧은지에 따라 전체가 한 바퀴 도는 크랭크 로커형, 두 링크가 모두 완전히 회전하는 더블 크랭크형, 둘 다 회전하지 못하고 흔들리기만 하는 더블 로커형으로 나뉘는데, 이 조건을 그라스호프 조건이라고 부릅니다. 저는 우선 크랭크 로커형으로 설계해서, 모터나 손잡이로 크랭크를 한 바퀴 돌리면 반대쪽 로커가 일정 각도 범위 안에서 왕복 운동을 하도록 만들어볼 계획입니다.
