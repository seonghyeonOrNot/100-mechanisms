# 010 Universal Joint (유니버설 조인트)

서로 어긋난 각도를 가진 두 축 사이에서도 회전력을 전달할 수 있게 해주는 기구로, 자동차 구동축이나 로봇 관절에 널리 쓰이는 3차원 회전 전달 항목입니다.

## 원리 설명

유니버설 조인트(훅 조인트)는 십자형 부품(크로스)을 중심으로 양쪽에 요크가 각각 직각으로 힌지 연결된 구조입니다. 두 축이 일직선이 아니라 어느 정도 각도를 이루고 있어도, 크로스가 두 방향으로 자유롭게 꺾이면서 회전력을 전달할 수 있습니다. 다만 입력축과 출력축의 각속도가 완전히 일정하게 전달되지는 않고 각도에 따라 미세하게 출렁이는 특성이 있어, 이 부분을 실제로 조립해서 체감해보고 싶습니다.

## 참고한 레퍼런스

## 시행착오

아직 실제 제작 전 단계입니다. 크로스와 요크 사이의 핀 결합 유격, 두 축 사이 각도에 따른 출렁임 등에서 문제가 생길 것으로 예상하며, 실제로 겪는 문제를 이 섹션에 채워나갈 예정입니다.
