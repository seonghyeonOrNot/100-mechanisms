# 009 Rack and Pinion (랙과 피니언)

원형 피니언 기어가 직선 랙 위를 굴러가며 회전 운동을 직선 운동으로 바꾸는, 자동차 조향 장치에도 쓰이는 기본적이고 실용적인 기구입니다.

## 원리 설명

피니언(작은 원형 기어)이 랙(직선으로 톱니가 파인 막대) 위를 맞물려 굴러가면서, 피니언의 회전이 랙의 직선 이동으로 변환됩니다. 반대로 랙을 고정하고 피니언을 밀면 피니언이 회전하게 되어 양방향 변환이 모두 가능합니다. 톱니 모듈과 피치원 지름을 정확히 맞추는 것이 맞물림 품질을 좌우하기 때문에, 이 부분을 기어 설계 공식에 맞춰 3D프린팅 출력해볼 계획입니다.

## 참고한 레퍼런스

507 Mechanical Movements  
기어 모듈/피치 설계 공식 자료  
자동차 조향 랙앤피니언 구조 설명 영상

## 시행착오

아직 실제 제작 전 단계입니다. 기어 모듈 계산 오류, 출력물의 톱니 맞물림 정밀도 등에서 문제가 생길 것으로 예상하며, 실제로 겪는 문제를 이 섹션에 채워나갈 예정입니다.
