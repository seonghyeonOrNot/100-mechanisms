# 005 Geneva Mechanism (제네바 기구)

연속 회전을 일정 간격으로 멈췄다가 움직이는 간헐 회전으로 바꿔주는 기구로, 필름 영사기나 인덱싱 테이블에 쓰이는 정교한 구조입니다.

## 원리 설명

제네바 기구는 회전하는 구동 휠에 달린 핀이, 슬롯이 여러 개 파인 제네바 휠에 순차적으로 맞물리며 회전을 전달합니다. 핀이 슬롯에 들어가 있는 구간에서만 제네바 휠이 회전하고, 핀이 빠져나온 나머지 구간에서는 제네바 휠이 잠금 원호에 의해 멈춰 있습니다. 슬롯의 개수가 곧 한 바퀴당 정지 구간의 수를 결정합니다. 저는 슬롯 4개짜리 제네바 휠로 설계해서, 90도씩 간헐 회전하는 구조를 만들어볼 계획입니다.

아직 실제 제작 전 단계입니다. 구동 핀과 슬롯 사이의 유격, 잠금 원호의 정밀도 등에서 문제가 생길 것으로 예상하며, 실제로 겪는 문제를 이 섹션에 채워나갈 예정입니다.
