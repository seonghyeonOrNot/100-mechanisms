# 006 Scotch Yoke (스카치 요크 기구)

슬라이더-크랭크와 같은 회전-직선 변환 기구이지만 훨씬 단순한 구조로, 순수한 단순 조화 운동(사인 곡선)을 만들어낼 수 있는 항목입니다.

## 원리 설명

스카치 요크는 크랭크 핀이 요크(yoke)에 파인 직선 슬롯 안에서 미끄러지도록 결합된 구조입니다. 커넥팅로드 없이 크랭크 핀이 슬롯을 직접 밀고 당기기 때문에, 슬라이더는 크랭크 각도의 사인 함수를 그대로 따르는 순수한 단순 조화 운동을 하게 됩니다. 구조가 단순한 대신 슬롯과 핀 사이의 마찰과 마모가 크다는 단점이 있어, 이 부분을 3D프린팅으로 어떻게 보완할지가 관건입니다.

## 참고한 레퍼런스

507 Mechanical Movements  
단순 조화 운동(SHM) 관련 물리 자료  
스카치 요크와 슬라이더-크랭크 비교 영상

## 시행착오

아직 실제 제작 전 단계입니다. 슬롯과 핀 사이의 마찰 및 마모, 출력 정밀도 등에서 문제가 생길 것으로 예상하며, 실제로 겪는 문제를 이 섹션에 채워나갈 예정입니다.
