# 007 Pantograph Mechanism (팬토그래프 기구)

평행 링크의 조합으로 원본 도형을 일정 비율로 확대하거나 축소해서 그대로 복제해주는 기구로, 조각기나 도면 확대기에 쓰이는 재미있는 항목입니다.

## 원리 설명

팬토그래프는 여러 개의 링크가 평행사변형 형태로 연결되어, 한쪽 끝(스타일러스)의 움직임이 정해진 비율로 확대되거나 축소되어 다른 쪽 끝(펜이나 조각 도구)에 그대로 전달되는 구조입니다. 링크의 길이 비율을 조정하면 확대/축소 비율을 자유롭게 바꿀 수 있습니다. 저는 우선 1대 2 확대 비율로 설계해서, 작은 도형을 그리면 두 배 크기로 복제되는 구조를 만들어볼 계획입니다.
