# 100 Mechanisms

100 Mechanisms는 다양한 기계 메커니즘을 분석하고, 설계하고, 기록하는 오픈 프로젝트입니다.

각 메커니즘의 움직임을 직접 구현하며 운동 원리, 자유도, 전달 구조, 설계 변수, 장단점, 그리고 실제 로봇 적용 사례까지 함께 정리합니다.

메커니즘으로 부터 움직임을 이해하고, 이를 로봇 시스템으로 연결하기 위한 지식 베이스를 구축하는 것이 이 프로젝트의 목표입니다.

## Why

'왜 어떤 로봇은 링크 구조를 사용하고, 왜 어떤 로봇은 캠이나 기어를 선택했으며, 왜 같은 움직임도 전혀 다른 방식으로 구현했을까.'

이론만으로는 이 질문에 충분히 답할 수 없었습니다.
직접 설계하고, 움직여 보고, 실패를 반복하면서 원리를 이해해 보기로 했습니다.
그 과정을 기록한 것이 바로 100 Mechanisms입니다.

* 어떻게 움직이는지
* 왜 이런 구조를 사용하는지
* 어떤 장단점이 있는지
* 실제 로봇에서는 어디에 활용되는지

이 프로젝트는 기계 메커니즘을 배우는 과정이자, 움직임을 이해하고 더 나은 로봇을 설계하기 위한 개인 프로젝트로 활용하고자 합니다.
